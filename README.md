Leonida Platinum — an offline guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI: a checklist saved in the browser with export and import, filters by grade, kind and earned status, a spoiler setting that hides the 28 hidden trophies until earned, a roadmap to the platinum, the one potentially missable trophy flagged, and a cited guide to every trophy in our own words. Trophy names, descriptions and grades are PlayStation's as listed by Exophase and PSNProfiles on 18 November 2026; methods come from PowerPyx's trophy guide, cited per trophy, and where a method is not yet confirmed the guide says so instead of inventing one.

## Run it

```sh
cd app && python3 -m http.server 8080
```

Then open http://localhost:8080 — or serve `app/` with any static file server. It works with the network off; the only files it loads are its own under `app/`.
